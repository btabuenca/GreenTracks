# GreenTracks

GreenTracks is a cross-platform mobile application developed within the <strong>SUTEE (Sustainable Technologies for Environmental Education)</strong> project. The app enables learners, educators, and citizens to collect, analyse, geolocate, and share environmental data using smartphone sensors and open environmental datasets. 【1-f6ab0c】

## Overview

GreenTracks promotes environmental awareness and inquiry-based learning by transforming smartphones into data collection tools. Users can measure environmental conditions, combine them with open environmental data sources, visualise results on dashboards, and support sustainability-focused learning activities. 【1-f6ab0c】

## Features

### Mobile Sensor Data Collection

GreenTracks allows users to collect environmental measurements directly from their smartphones:

- Noise level measurement using the device microphone
- Light intensity measurement using the device camera
- Configurable sampling cadence
- Multi-language support
- Real-time statistical summaries including:
  - Maximum
  - Minimum
  - Average
  - Standard deviation
  - First quartile (Q1)
  - Third quartile (Q3)
- Data reset and management options 【1-f6ab0c】

### Open Environmental Data

The application integrates environmental information from open APIs, including:

- Temperature
- Humidity
- Wind conditions
- Air Quality Index (AQI)
- PM10
- PM2.5
- Carbon monoxide (CO)
- Nitrogen oxides (NOx)
- Ultraviolet radiation (UV)
- Ozone (O₃)

Users can compare local conditions with data from other regions around the world. 【1-f6ab0c】

### Geolocated Observations

GreenTracks enables users to:

- Geolocate measurements
- Record observation routes
- Annotate environmental observations
- Associate measurements with specific places and contexts 【1-f6ab0c】

### Data Sharing and Visualization

Collected data can be:

- Shared with other users
- Exported as CSV files
- Visualised in dashboards
- Combined with open data layers
- Embedded into educational resources and VISH learning environments 【1-f6ab0c】

### Learning Activities

GreenTracks is connected to a repository of environmental learning activities that support inquiry-based learning and environmental education inside and outside the classroom. 【1-f6ab0c】
