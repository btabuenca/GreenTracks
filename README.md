GreenTracks is a mobile application developed within the **SUTEE (Sustainable Technologies for Environmental Education)** project to support environmental education through data collection, citizen science, and inquiry-based learning.

The application transforms smartphones into environmental sensing tools, enabling users to collect, visualize, and share environmental information while promoting sustainability awareness and data literacy.

---

## 📱 Main Features

### Environmental Data Collection

GreenTracks allows users to collect environmental measurements using smartphone sensors:

- Noise monitoring
- Light intensity monitoring
- Geolocation-enabled observations
- Route tracking
- Environmental annotations

### Environmental Open Data

The application integrates environmental information from external data sources, including:

- Temperature
- Humidity
- Wind conditions
- Air Quality Index (AQI)
- PM2.5 and PM10
- Ozone (O₃)
- Carbon Monoxide (CO)
- Nitrogen Oxides (NOx)
- UV Radiation

### Data Analytics

Collected measurements can be analyzed using:

- Average values
- Minimum values
- Maximum values
- Standard deviation
- Quartiles
- Historical records

### Data Sharing

Users can:

- Export measurements as CSV
- Share observations
- Compare records between locations
- Contribute to educational and citizen science activities

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Android Studio or VS Code
- Android Emulator or Physical Device

### Installation

Clone the repository:

```bash
git clone https://github.com/btabuenca/GreenTracks.git
```

Navigate to the project:

```bash
cd GreenTracks
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
